# airbnb-market-analysis-python
Data cleaning and exploratory analysis on global Airbnb listings using Python &amp; Pandas. A better way to understand how data can dictate behavior even in the vacation period.

## 🔍 Key Research Questions

1. **Country Representation & Pricing:** Which countries are most represented on the platform, and how does the average price vary among them?
 
2. **Amenity Premium:** What is the average price difference for listings offering premium amenities (e.g., Pools, Pet-Friendly) compared to standard properties?

3. **Rating vs. Price:** Do higher-rated accommodations charge higher daily rates, or is there no correlation between review scores and price?

4. **Host Concentration:** What is the ratio of single-property hosts to multi-property hosts, and do multi-hosts charge higher prices?

5. **Cost Efficiency per Guest:** How does the "cost per guest" metric scale as listing capacity (bedrooms and maximum guests) increases?
